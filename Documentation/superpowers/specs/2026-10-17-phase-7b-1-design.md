# Duo Angle Phase 7B.1 设计规格

日期：2026-10-17

## 目标

为现有 Duo Angle 项目完成一次聚焦的发布准备，保留现有测角、显示布局、目标监测、持久化、触觉反馈和 StoreKit 架构。此阶段不做 7B.2 硬件验证或 App Store 提交。

## 范围

1. 使用 Apple String Catalog 为简体中文（`zh-Hans`）、繁体中文（`zh-Hant`）、英语（`en`）、日语（`ja`）和韩语（`ko`）本地化全部面向用户的文字；跟随系统语言，不增加应用内语言选择。
2. 审计实际数据流、存储、网络、第三方 SDK、日志、权限和交易处理；撰写中英文隐私政策、隐私披露核对清单及适用的隐私清单声明。
3. 移除 MainView 上的诊断开关及其仅用于该交互的展示状态，保留有开发价值的内部诊断能力和 DEBUG 日志。
4. 保留用户提供的深色图标设计，并依据同一图稿制作浅色外观变体；不改动中心符号或重新设计图标。使用当前 Xcode/SDK 支持的 App Icon 资产配置，不手工重复添加圆角遮罩。
5. 完善英文与简体中文 README，记录真实的模拟器验证与硬件验证边界、构建方法、隐私架构和当前限制，并创建 `Documentation/PHASE_7B_1_REPORT.md`。
6. 将 Xcode 项目的签名团队切换到 新的 Apple Developer 账户所属且当前 Xcode 可用的开发团队。具体 Team ID 必须从 Xcode 可验证的账户/签名上下文取得，不猜测；账户登录本身不由项目文件代替。
7. 使用用户已提供的公开仓库 `https://github.com/hutianchi123/DuoAngle`；不创建重复仓库、不改写历史、不强推。推送前检查待提交文件、历史、忽略规则和敏感凭据。

## 实施约束

- 开始修改前记录并保留当前工作区的修改和未跟踪文件；仅纳入本阶段明确需要的文件。
- 遵循已有 SwiftUI、资产目录和项目组织方式，避免重构测量及监测架构。
- 商店价格继续使用 `Product.displayPrice`；不进行真实付款。
- 不添加开源许可证、不虚构开发者联系邮箱、不宣称实体设备验证已完成。
- 发布准备变更最终合并为一个提交：`chore: prepare Duo Angle for public release`。若历史中发现可能暴露的秘密，停止公开推送并报告。

## 验证

- 通过 Xcode MCP 构建 Debug 与 Release。
- 不运行完整回归测试套件；只做必要的定向检查：本地化资源/关键界面文案、诊断入口缺失、浅色与深色图标资源以及必要的启动/界面检查。
- 所有 Simulator 操作后保持模拟器开机；可重新编译应用，不执行关机操作。
- 不做真实付款、实体 Duo 验证或 App Store 提交。

## 完成条件与剩余事项

代码和文档符合上述范围，必要构建和定向检查结果写入阶段报告，仓库安全检查通过后提交并推送到已给出的公开仓库。App Store Connect 的商店元数据翻译、隐私标签最终填写、稳定政策 URL 核验，以及真实硬件验证仍作为人工后续事项；若签名账户无法由当前 Xcode 会话确认或 GitHub 推送权限缺失，则完成可完成的本地工作并明确报告阻塞项。
